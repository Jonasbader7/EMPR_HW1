# EMPR – Homework I (BFH, HS2026)

RStudio-Projekt für Homework I im Modul EMPR – Modern Programming in R.

- `HW1_Part1_Individual.qmd` – Aufgaben 1–4 (individuell)
- `HW1_Part2_Group.qmd` – Aufgaben 5–6 (Gruppe)
- `data/Data_HW1.xlsx` – Umfragedaten für Aufgabe 5

`data/NDCP2022.xlsx` (Aufgabe 6, 92 MB) ist nicht im Repo. Von Moodle oder
https://www.dol.gov/sites/dolgov/files/WB/NDCP2022.xlsx herunterladen und in `data/` ablegen.

Öffnen mit Doppelklick auf `EMPR_HW1.Rproj`. Benötigte Pakete (einmal in der Console):

```r
install.packages(c("tidyverse", "nycflights23", "ggridges", "kableExtra", "readxl", "janitor"))
```
